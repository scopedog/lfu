## Findings

### 1. `lustre/utils/lfs.c` (line 6675)

(minor) If the patch is refreshed: a target named without its fsname is rejected with a message that contradicts the input:

    # lfs find --target MDT0000 --type f
    find: 'MDT0000' is not an MDT or an OST

lfs_find_label_is() wants a '-' before the role, so a short name like this fails the check even though it is an MDT. Rejecting it is right, since a node can serve more than one filesystem. The wording could name the expected form, though, e.g. "'%s' is not a target name like FSNAME-MDT0000", so the user is not told an MDT is not an MDT. The same message covers a lower-case label such as testfs-mdt0000.
